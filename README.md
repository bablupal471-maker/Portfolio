# Bablu Pal | WordPress & UI Developer Portfolio 🚀

A responsive personal portfolio website for **Bablu Pal**, a Senior UI and WordPress Developer. The portfolio highlights professional experience, technical skills, selected WordPress projects, education, and contact options.

## Features ✨

- 📱 Responsive, mobile-first design
- ⌨️ Typewriter effect for the hero role line
- 🌌 Cursor-follow background glow
- 📊 Animated count-up statistics in the About section
- ✉️ Contact form powered by Web3Forms
- 🧩 Skills, experience, projects, education, and profile sections
- 🔗 Social links for LinkedIn, GitHub, email, WhatsApp, and phone
- 🎨 Bootstrap-based layout with custom CSS styling

## Tech Stack 🛠️

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Bootstrap Icons
- Web3Forms

## Project Structure 📁

```text
Portfolio/
├── index.html              # Main portfolio page
├── style.css               # Custom styles extracted from index.html
├── script.js               # Portfolio interactions and animations
├── README.md               # Project documentation
├── assets/                 # Website assets, including profile media
├── img/                    # Image resources
```

## Getting Started 🏁

### Clone the repository

Replace `<your-repository-url>` with the URL of your Git repository:

```bash
git clone <your-repository-url>
cd Portfolio
```

### Run the project

Open `index.html` directly in a browser, or serve the folder with a local development server. No build step or package installation is required.

> The contact form requires a valid Web3Forms access key configured in `index.html`.
